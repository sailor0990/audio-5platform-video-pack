# 五平台规格核对表

> 说明：下列为**基准值**，用于生成与自检。平台规则会变，**上传前务必以官方最新为准**。
> 权威入口：微信视频号 findeross.weixin.qq.com｜抖音 creator.douyin.com｜小红书 creator.xiaohongshu.com｜西瓜 studio.ixigua.com｜B站 创作中心 bilibili.com。

## 版式分组（先分类，再适配）

| 组 | 平台 | 画面比例 / 分辨率 | 说明 |
|----|------|------------------|------|
| 竖屏组 | 微信视频号、抖音、小红书 | 9:16 · 1080×1920 | 一套竖屏帧可三平台共用 |
| 横屏组 | 西瓜视频、哔哩哔哩 | 16:9 · 1920×1080 | 一套横屏帧可两平台共用 |

平台差异主要落在**封面比例、标题字数、正文长度、话题数量、码率上限**，画面本身在组内可复用。

## 逐平台规格

### 微信视频号（竖屏组）
| 项 | 要求 |
|----|------|
| 比例/分辨率 | 画面比例 0.33~3.0，建议 9:16；1080×1920 |
| 时长 | 3 秒 ~ 8 小时 |
| 体积 | ≤ 20 GB（助手端上传） |
| 编码 | MP4 / H.264 + AAC |
| 标题 | 描述 ≤ 1000 字；描述 >16 字时出现「短标题」框，短标题 ≤16 字 |
| 正文/描述 | ≤ 1000 字 |
| 话题 | 描述内 #话题#，无硬上限，建议 3~5 |
| 封面 | 可自定义上传 |
| 发布入口 | findeross.weixin.qq.com → 首页 > 发表视频 |

### 抖音（竖屏组）
| 项 | 要求 |
|----|------|
| 比例/分辨率 | 竖屏 9:16，推荐 1080×1920 |
| 时长 | 网页端 ≤ 15 分钟（≤4GB）；客户端 ≤ 10GB，长视频权限 ≤ 60 分钟 |
| 体积 | 网页端 ≤ 4 GB |
| 编码 | MP4 / H.264 |
| 标题 | ≤ 100 字（前 30 字最关键） |
| 正文/描述 | 含话题，建议≤ 2000 字 |
| 话题 | ≤ 5 个 |
| 封面 | 推荐 1125×1466（约 3:4），必勾「高清发布」防二次压缩 |
| 发布入口 | creator.douyin.com |

### 小红书（竖屏组）
| 项 | 要求 |
|----|------|
| 比例/分辨率 | 支持 9:16 / 3:4；视频常用 1080×1920 |
| 时长 | 视频笔记 ≤ 60 分钟 |
| 体积 | App 端 ≤ 2 GB；网页端支持 |
| 编码 | MP4 / H.264 |
| 标题 | ≤ 20 字（钩子前置） |
| 正文 | ≤ 1000 字（支持 emoji、换行） |
| 话题 | 建议 5~10 个 |
| 封面 | 推荐 3:4 · 1080×1440；**务必用自定义封面**，勿用系统截帧 |
| 发布入口 | creator.xiaohongshu.com（或 App 直接发） |

### 西瓜视频（横屏组）
| 项 | 要求 |
|----|------|
| 比例/分辨率 | 横屏 16:9，推荐 ≥ 1920×1080 |
| 时长 | 电脑端不限；中视频伙伴计划要求 ≥ 1 分钟原创横屏 |
| 体积 | ≤ 32 GB |
| 编码 | MP4 / H.264 + AAC |
| 标题 | 5 ~ 30 字 |
| 正文/简介 | 建议 ≤ 1000 字 |
| 话题 | ≤ 10 个 |
| 封面 | ≥ 1920×1080、16:9、≤ 5 MB |
| 发布入口 | studio.ixigua.com |

### 哔哩哔哩 / B站（横屏组）
| 项 | 要求 |
|----|------|
| 比例/分辨率 | 横屏 16:9，推荐 1920×1080；最大 1920×1080 |
| 时长 | 支持较长视频（数小时） |
| 体积 | 单文件 ≤ 4 GB |
| 编码 | MP4/FLV；H.264/AVC，码率 ≤ 6000 kbps，峰值 ≤ 24000 kbps；音频 AAC ≤ 320 kbps / 44.1 kHz / 声道≤2 / yuv420 |
| 标题 | ≤ 80 字（网页端；前 10 字突出核心） |
| 简介 | ≤ 2000 字（可含时间轴） |
| 标签 | 3~5 个（≤10，每个 ≤12 汉字），含 1 主标签 + 长尾标签 |
| 封面 | 16:9 · 1920×1080（1146×717 亦可）；≤ 5 MB；JPG/PNG |
| 必勾 | 正确分区、声明原创、《创作公约》 |
| 发布入口 | bilibili.com → 创作中心 → 投稿 |

## 通用技术基线（横屏组建议）
- 视频：H.264 / yuv420p / 30fps / CRF 18~21（横屏取 19，竖屏取 21）
- 音频：AAC 192k / 44.1kHz / 立体声
- 封装：MP4，`-movflags +faststart`
- B站码率上限 6000kbps 是最严格项，横屏成片导出时注意控制码率（CRF 19 通常满足）。

## 规格核对方法
用 `scripts/check_specs.py` 读取实测值（ffprobe 尺寸/时长/码率/体积 + 封面尺寸），逐项与上表比对，输出「本片 / 要求 / 结论」三列。凡不满足项标红并在发布包中提示。
