# 文件命名、目录结构与输出清单

## 目录结构（建议固定）

```
video_pack/
├── assets/
│   ├── audio.wav                 # 统一工作音频（44.1k/立体声）
│   ├── audio_original.mp3        # 用户原始音频（保留）
│   ├── silence.txt               # ffmpeg silencedetect 结果
│   ├── timeline.json             # 段/句 时间轴（start/end/dur）
│   ├── frames_vertical.json      # 竖屏版式帧清单（file+dur）
│   └── frames_horizontal.json    # 横屏版式帧清单（file+dur）
├── frames/
│   ├── vertical/0001.png ...     # 竖屏字幕帧/信息图（1080×1920）
│   └── horizontal/0001.png ...   # 横屏字幕帧/信息图（1920×1080）
├── covers/
│   ├── wechat_cover.png
│   ├── douyin_cover.png          # 3:4 1125×1466 或 1080×1440
│   ├── xiaohongshu_cover.png     # 3:4 1080×1440
│   ├── xigua_cover.jpg           # 16:9 ≥1920×1080
│   └── bilibili_cover.png        # 16:9 1920×1080
├── videos/
│   ├── vertical_1080x1920.mp4    # 竖屏成片（微信/抖音/小红书共用）
│   └── horizontal_1920x1080.mp4  # 横屏成片（西瓜/B站共用）
├── publish_kits/
│   ├── 微信视频号发布包.html
│   ├── 抖音发布包.html
│   ├── 小红书发布包.html
│   ├── 西瓜视频发布包.html
│   ├── 哔哩哔哩发布包.html
│   └── 发布文案_纯文本.txt        # 五平台文案合订，手机复制用
└── 成果说明.md
```

## 文件命名规范

- 视频：`<版式>_<宽>x<高>.mp4`（如 `vertical_1080x1920.mp4`）。如需区分主题：`<主题>_<版式>_<宽>x<高>.mp4`。
- 封面：`<平台>_cover.<png|jpg>`。
- 发布包：`<平台>发布包.html`；文案：`<平台>发布文案.txt` 或合订 `发布文案_纯文本.txt`。
- 帧：`frames/<版式>/<4位序号>.png`（0001 起）。
- 统一要求：小写英文 + 数字 + 中文平台名；不使用空格，用下划线或直接拼接；避免特殊字符。

## 输出文件清单（交付时逐项核对）

| 类别 | 文件 | 数量 | 说明 |
|------|------|------|------|
| 视频 | vertical / horizontal 成片 | 2 | 竖屏组共用竖屏、横屏组共用横屏；若需差异化再拆 |
| 封面 | 五平台封面 | 5 | 比例按平台 |
| 发布包 | 五平台 HTML | 5 | 自包含，内嵌封面 base64，可离线打开 |
| 文案 | 纯文本 txt | 1~5 | 手机端备用 |
| 说明 | 成果说明.md | 1 | 文件清单 + 规格结论 + 待确认项 |
| 中间件 | timeline / frames json、帧图 | — | 便于复用与二次调整 |

## 需人工确认清单（随成果说明一并交付）

1. 音频内容与主题是否一致、有无口误/敏感内容。
2. 标题主推款与备选款的取舍。
3. 正文卖点与话题标签是否贴合账号定位。
4. 封面选型（多版备选时由用户定）。
5. 各平台规格是否以官方最新为准（基准表仅供自检）。
6. 分区/原创声明等平台特定设置。
7. **发布动作本身**——本流程不代发，由人工完成。
