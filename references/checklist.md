# 发布前检查清单（可逐项勾选）

> 每个平台发布前逐项核对；任一未过项不得发布。带 ⚠ 的为高危项。

## 一、视频技术检查
- [ ] 分辨率与比例正确（竖屏组 1080×1920 / 横屏组 1920×1080）
- [ ] 编码 H.264 + AAC，封装 MP4，`+faststart`
- [ ] 帧率 30fps，像素格式 yuv420p
- [ ] 体积在平台上限内（抖音网页 4GB / 西瓜 32GB / B站 4GB / 视频号 20GB / 小红书 App 2GB）
- [ ] 时长在平台上限内（抖音网页 15 分钟 / 小红书 60 分钟等）
- [ ] ⚠ 视频总时长与音频严格对齐（误差 < 0.05s），无末尾截断/黑屏
- [ ] ⚠ 横屏成片码率 ≤ 6000 kbps（B站上限），避免被二次压制
- [ ] 画面无其他平台 Logo / 水印 / 未授权素材
- [ ] 抽帧复核：开头、中段、结尾字幕与画面无遮挡、无重叠

## 二、封面检查
- [ ] 比例正确（竖屏组 3:4 或 9:16；横屏组 16:9）
- [ ] 尺寸达标（小红书 1080×1440 / 抖音 1125×1466 / 西瓜·B站 ≥1920×1080）
- [ ] 体积 ≤ 5 MB（西瓜/B站）
- [ ] ⚠ 上传时选「自定义封面」，不用系统默认截帧
- [ ] 封面文字在移动端首屏可读，无出血/裁切
- [ ] 封面内容与视频主体一致，无违规元素（色情/暴力/政治/钱币/国旗等）

## 三、文案检查
- [ ] 标题字数符合平台上限（微信短标题≤16 / 抖音≤100 / 小红书≤20 / 西瓜5~30 / B站≤80）
- [ ] 标题钩子前置（抖音前 30 字、B站前 10 字、小红书首行）
- [ ] 正文/简介字数达标（小红书≤1000 / B站≤2000 / 视频号≤1000）
- [ ] 话题数量符合（抖音≤5 / 西瓜≤10 / 小红书5~10 / B站标签3~5）
- [ ] 话题标签无堆砌、与内容相关
- [ ] 评论区置顶文案已准备（可提升互动/转化）
- [ ] ⚠ UTF-8 编码正确，中文无乱码（B站对乱码会静默丢标签）

## 四、合规与发布设置
- [ ] ⚠ 勾选「原创/自制」声明
- [ ] ⚠ 选对分区（B站知识/科技等必须准确，否则限流）
- [ ] 背景音乐/素材版权清晰（用平台免版税库或已授权）
- [ ] 无违规词、无敏感内容
- [ ] 可见范围正确（公开）
- [ ] 预览无误后再点发布（发布不可逆，谨慎）
- [ ] 发布后回填置顶评论

## 五、归档检查
- [ ] 视频 / 封面 / 发布包 html / 文案 txt 四件套齐全，命名规范
- [ ] 成果说明.md 已生成（文件清单 + 规格结论 + 待人工确认项）
- [ ] 规格核对结果随包留存，便于复查
